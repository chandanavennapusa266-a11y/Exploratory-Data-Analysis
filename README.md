# Data Analytics Project 2 — Exploratory Data Analysis

## Objective
Perform Exploratory Data Analysis (EDA) on the cleaned e-commerce order dataset to understand patterns, trends, distributions, outliers, and relationships.

## Project Requirements Covered
- Basic statistics: count, mean, median and additional descriptive statistics
- Trends and distributions
- Outlier detection
- Categorical analysis
- Correlation analysis
- Key observations

## Dataset
The analysis uses the cleaned output from Data Analytics Project 1.

## Main Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Findings Generated from This Dataset
- Top product by order count: Printer
- Highest-revenue product: Chair
- Most common payment method: Online
- Most common order status: Cancelled
- Most common referral source: Instagram
- Peak revenue month: 2024-06-30
- Peak monthly revenue: 68068.54
- Strongest numerical correlation by absolute value: UnitPrice vs TotalPrice (0.717)

## Important EDA Principle
Outliers are investigated rather than automatically removed because an unusual observation can be a valid business event.
